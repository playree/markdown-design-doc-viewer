# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Report them privately from the **Security** tab of this repository: **Report a vulnerability** (GitHub's private vulnerability reporting). Include the affected product and version, the steps to reproduce, and the impact you expect.

This project is maintained by an individual. Reports are reviewed and fixed as time allows; no response time is guaranteed.

## Supported versions

Only the latest releases receive security fixes:

- The VS Code extension "Markdown Design Doc Viewer"
- The CLI (npm package `markdown-design-doc-viewer`)
- The desktop app (releases tagged `desktop-vX.Y.Z`)

## 脆弱性の報告（日本語）

脆弱性は公開の Issue・Pull Request には書かず、このリポジトリの **Security** タブの **Report a vulnerability**（GitHub の非公開の脆弱性報告）から報告してください。対象の製品とバージョン、再現手順、想定される影響を書いてください。

個人で保守しているため、確認・修正は順次行います（対応の期限はお約束できません）。修正の対象は、拡張機能・CLI（npm パッケージ）・デスクトップアプリのそれぞれ最新のリリースです。
