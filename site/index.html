Read design docs with diagrams and steps side by side

A viewer for design documents written in Markdown. mermaid sequence diagrams and flowcharts are shown beside their step descriptions, and each arrow (or node) is linked to its heading.

Install for VS Code Try the live sample

The sample is a design document exported to HTML. Hover the arrows and headings to try the highlighting.

Still plain Markdown

The links are written with mermaid comments and HTML comments, so the same file still renders correctly on GitHub and in other Markdown previews.

```mermaid
%% @link-headings
sequenceDiagram
    Auth->>DB: Fetch user
    %% @ref Issue token
    Auth-->>API: Return access token
```

### Fetch user

Look up the user by id.

### Issue token

Issue a JWT valid for one hour.

  1. Mark the diagram

    Write %% @link-headings in a sequence diagram or a flowchart. It is shown side by side with the headings after it.

  2. Write the steps as headings

    An arrow or node is linked to the heading with the same text. Numbered headings like ### 3. Fetch user match too.

  3. Use @ref when they differ

    %% @ref <heading> links the next arrow to a heading with other words. Missing links are reported as warnings.

Made for design documents

Hover or click an arrow to highlight its step, or click a heading to find it in the diagram. The diagram stays in view while the steps scroll.

Flowcharts too

Flowcharts are linked the same way, with their nodes in place of arrows. Horizontal flowcharts are shown above their steps.

Find missing steps

Arrows without a heading are faded, and headings without an arrow are marked. In VS Code they are also reported in the Problems panel, with quick fixes.

A header from the front matter

With type: design_doc in the YAML front matter, the title, version, product, status and updated date are shown as the document's header.

The notation of design documents

GitHub alerts, task lists, footnotes, collapsible sections and syntax-highlighted code blocks are rendered. Long tables keep their header row in view.
