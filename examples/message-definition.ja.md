# 在庫照会 API 電文定義

項目の表のサンプルです。表の直前のコメント（`<!-- table: … -->`）で、物理名を項目名の下にまとめ、項目の入れ子を階層の列からツリーで表示します。▾ をクリックすると子の項目を折りたたみ、行にマウスを乗せるとその親と子をハイライトします。GitHub などでは、ふつうの表として表示されます。

## 1. 概要

- 店舗の端末から在庫照会 API（`POST /v1/stock-inquiries`）に、商品の在庫と入荷予定を問い合わせる。
- 本文は JSON（UTF-8、`Content-Type: application/json`）。要求・応答とも、共通部の `control` の後ろに業務部を置く。
- 項目の表の「必須」は、○ が必須、△ が説明に書いた条件のときだけ必須、空欄が任意。任意の項目は、値がなければ項目ごと省略する（`null` は送らない）。

## 2. 要求

### 2.1 例

```json
{
  "control": { "requestId": "c0a8012e-5f3b-4e8a-9d61-2b7c4e9f1a03", "sentAt": "2026-10-15T09:30:00+09:00" },
  "inquiry": {
    "storeCode": "0123",
    "items": [
      { "janCode": "4901234567894", "quantity": 2 },
      { "janCode": "49012342" }
    ]
  }
}
```

| No | 階層 | 項目名 | 物理名 | 型 | 形式 | 桁 最小 | 桁 最大 | 必須 | 説明 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 1 | 照会条件 | `inquiry` | object | - | - | - | ○ | |
| 2 | 2 | 店舗コード | `storeCode` | string | 数字 | 4 | 4 | ○ | 照会する店舗 |

| 5 | 3 | 希望数量 | `quantity` | integer | - | 1 | 9999 | | 省略時は 1。桁は値の範囲 |

## 3. 応答

### 3.1 例

正常時（HTTP 200）:

```json
{
  "control": { "requestId": "c0a8012e-5f3b-4e8a-9d61-2b7c4e9f1a03", "respondedAt": "2026-10-15T09:30:01+09:00" },
  "result": {
    "status": "ok",
    "stocks": [
      { "janCode": "4901234567894", "stockQuantity": 12 },
      { "janCode": "49012342", "stockQuantity": 0, "arrival": { "date": "2026-10-20", "quantity": 24 } }
    ]
  }
}
```

エラー時（HTTP 4xx・5xx）:

```json
{
  "control": { "requestId": "c0a8012e-5f3b-4e8a-9d61-2b7c4e9f1a03", "respondedAt": "2026-10-15T09:30:01+09:00" },
  "result": {
    "status": "error",
    "error": { "code": "E00003", "message": "JAN コードが登録されていません。", "field": "inquiry.items[1].janCode" }
  }
}
```

| 16 | 3 | 入荷予定 | `arrival` | object | - | - | - | | 入荷予定があるときのみ |

## 4. エラーコード

| コード | HTTP ステータス | 内容 | 端末の対応 |
|---|---|---|---|
| `E00001` | 404 | 店舗コードが存在しない | 端末の設定を確認する |
| `E00002` | 400 | 商品の数が 50 を超えている | 分けて照会する |
| `E00003` | 422 | JAN コードが登録されていない | 商品マスタを確認する |
| `E99999` | 500 | システムエラー | 時間をおいて再照会する |
